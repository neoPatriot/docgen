# Генератор Документов

Это простое веб-приложение на Flask, которое генерирует документы `.docx` из шаблона `.docx` и таблицы с данными `.xlsx`.

В шаблоне пользователь создает метки с названием столбцов в таблице с данными (например, `{{имя}}`, `{{дата}}`). Программа подставляет данные из таблицы на место меток. Каждая строка таблицы создает отдельный документ. Все сгенерированные документы упаковываются в один ZIP-архив для удобного скачивания.

## Как это работает

1.  **Загрузка**: Пользователь загружает через веб-интерфейс два файла:
    *   Шаблон документа в формате `.docx`.
    *   Таблицу с данными в формате `.xlsx`.
2.  **Генерация**: Приложение считывает данные из `.xlsx` файла. Для каждой строки данных оно создает копию `.docx` шаблона и заменяет в ней все метки вида `{{имя_колонки}}` на соответствующие значения из этой строки.
3.  **Скачивание**: Все созданные `.docx` файлы упаковываются в один ZIP-архив, который становится доступен для скачивания.

### Инструкция по запуску проекта в PyCharm

1.  **Откройте проект:**
    *   Запустите PyCharm.
    *   Выберите `File` -> `Open...` (Файл -> Открыть...) и укажите папку с проектом.

2.  **Создайте и настройте виртуальное окружение:**
    *   PyCharm обычно автоматически предлагает создать виртуальное окружение для нового проекта. Если нет, сделайте это вручную:
    *   Откройте настройки: `File` -> `Settings...` (или `PyCharm` -> `Preferences...` на macOS).
    *   Перейдите в раздел `Project: [название вашего проекта]` -> `Python Interpreter`.
    *   Нажмите на значок шестеренки и выберите `Add...`.
    *   В открывшемся окне выберите `Virtualenv Environment`, убедитесь, что выбрана опция `New environment`, и нажмите `OK`. Это создаст изолированное окружение для проекта, что является лучшей практикой.

3.  **Установите зависимости:**
    *   После создания проекта и настройки интерпретатора PyCharm, скорее всего, обнаружит файл `requirements.txt` и покажет уведомление с предложением установить зависимости. Нажмите на `Install requirements`.
    *   Если уведомления нет, откройте **Терминал** в нижней части PyCharm (`View` -> `Tool Windows` -> `Terminal`).
    *   Убедитесь, что виртуальное окружение активировано (в начале командной строки должно быть что-то вроде `(venv)`).
    *   Выполните команду:
        ```bash
        pip install -r requirements.txt
        ```

4.  **Запустите приложение:**
    *   Найдите файл `app.py` в дереве проекта слева.
    *   Кликните по нему правой кнопкой мыши.
    *   В контекстном меню выберите `Run 'app'`.
    *   В нижней части PyCharm откроется окно `Run`, где вы увидите логи сервера. Если все в порядке, там будет строка, похожая на:
        ```
        * Running on http://127.0.0.1:5000
        ```

5.  **Откройте приложение в браузере:**
    *   Откройте ваш любимый веб-браузер (Chrome, Firefox и т.д.).
    *   Перейдите по адресу, который указан в логах запуска — обычно это **http://127.0.0.1:5000**.

После этого в браузере откроется страница веб-приложения, и вы сможете загрузить файлы для генерации документов.
